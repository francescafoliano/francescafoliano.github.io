Code is shared through GitHub. Data are not included where they are held under restricted access; each repository's README explains how to obtain them.

**Panel of schools in England, 2002–2017/18** · [Repository](https://github.com/USERNAME/england-school-panel)

Stata code that builds a consistent panel of all schools in England from 2002 to 2017/18. It accounts for mergers, URN changes and academisation, removes school splits, and assigns a unique URN to each school since 2002. Uses EduBase and LinkedEdubase data and the ONS Postcode Directory.

**Estimating income poverty in the presence of missing data and measurement error** (*JBES*, 2011) · [Repository](https://github.com/USERNAME/jbes-income-poverty-bounds)

Code for cleaning the data and computing the bounds and bootstrapped confidence intervals.
